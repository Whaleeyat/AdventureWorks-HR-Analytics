# AdventureWorks-HR-Analytics
An analysis of employee data from the AdventureWorks dataset, focusing on demographics, pay, tenure, departments, and sales performance.
## About the Project

This project is an analysis of employee data from the AdventureWorks dataset. I looked at areas such as employee demographics, departments, pay, tenure, and sales performance.

I wanted to understand the workforce better and see what the data could tell me about the organisation.

## Tools Used

- Power BI
- Excel
- Power Query
- DAX

## Areas Analysed

- Workforce composition
- Employee demographics
- Compensation
- Employee tenure
- Sales representative performance
- Key insights and recommendations

## Key Findings

- 290 employees were analysed across 16 departments.
- 29% of the workforce was female.
- 84% of employees fell within the 4–6 year tenure range.
- The top five sales representatives generated 55% of cumulative revenue.
- Production had the largest workforce but the lowest average pay.
